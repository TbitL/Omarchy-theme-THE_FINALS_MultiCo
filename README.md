# MultiCo — Omarchy theme

A dark terminal-inspired Omarchy theme based on the OS that MultiCo Uses in the "Uploading S10" teaser video.


| Role | Color |
|---|---|
| Borders and text | `#d4f3f8` |
| Containers, boxes, and accent | `#519bea` |
| Warnings | `#ce1416` |
| Main surface and background | `#151d41` |

## Backgrounds

- `backgrounds/bghome.png` is the home/desktop wallpaper.
- `unlock.png` and `preview-unlock.png` use `bglock.png` for the lock/unlock screen.
- `preview.png` uses the home wallpaper for the theme selector preview.

## Install locally

Copy this `multico` directory to `~/.config/omarchy/themes/multico`, then select **multico** from the Omarchy theme menu or run the equivalent theme switch command.
